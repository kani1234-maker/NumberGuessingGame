# Number Guessing Game (Java)
A fun and interactive **console-based Number Guessing Game** developed in **Java**. The game generates a random number, and the player must guess it within a limited number of attempts. After each guess, the game provides hints to help the player determine whether the correct number is higher or lower.
## Features
* Random number generation for every round
*Three difficulty levels:
  * **Easy:** 1–50 (10 attempts)
  * **Medium:** 1–100 (7 attempts)
  * **Hard:** 1–200 (5 attempts)
* Higher/Lower hints after every guess
* Attempt counter displayed during gameplay
* Win/Lose messages
* Play Again option
* Multi-round game summary with score history
* Simple and user-friendly console interface
## Technologies Used
* Java
* Object-Oriented Programming (OOP)
* Java Collections (`ArrayList`)
* `Scanner` for user input
* `Random` class for number generation
## How to Run
1. Clone this repository.
2. Navigate to the project folder.
3. Compile the program.
4. Run the program.
## Gameplay
1. Select a difficulty level.
2. The system generates a random number.
3. Enter your guesses.
4. Receive one of the following hints:
   * **Too High!**
   * **Too Low!**
   * **Correct!**
5. Guess the number before you run out of attempts.
6. Choose whether to play another round.
7. View your game summary after exiting.
